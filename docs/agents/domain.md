# Domain Docs

This repo uses a single-context layout: `CONTEXT.md` at the root and ADRs in `docs/adr/`.

Before exploring an area, read `CONTEXT.md` and any relevant ADRs. If they do not exist yet, proceed silently. The domain-modeling skill creates them when terms or decisions are resolved.

Use terms defined in `CONTEXT.md` consistently in issues, proposals, hypotheses, and tests. If a proposed change conflicts with an ADR, flag the conflict explicitly.
